# Translink Merchant: UX case study

A UX case study by **Suvarna Myneni**, AI-Native UX Designer in Hyderabad, about the Translink Merchant Android app she designed for Cubic Transportation Systems. Retailers in South East Queensland use it to sell and top up go cards.

The page uses the shared case-study layout and this process: My Role, Design Process, Problem, Stakeholders, End Users, Research Methods, Competitive Analysis, User Personas, Design Decisions, Prototype, UI Kit, Final Design, Outcome, Metrics.

All screens are crops of the project design board. Public facts link to their sources. The Metrics section lists design targets, not measured production results. The page styles come from `case-study.css`.

**Live site:** https://suvarnamyneni.github.io/cubic-translink-merchant-case-study/

## View it

Open `index.html` in a browser. There is no build step.
