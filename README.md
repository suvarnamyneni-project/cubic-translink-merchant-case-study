# Translink Merchant: UX case study

A UX case study by **Suvarna Myneni**, AI-Native UX Designer in Hyderabad, about the Translink Merchant Android app she designed for Cubic Transportation Systems. Retailers in South East Queensland use it to sell and top up go cards.

The page follows this process: Design Problem, Stakeholders, End-users, Primary Research, Secondary Research, Competitive Analysis, User Personas, Design Decisions, Prototype, UI Kit, Final Designs, Outcome, Metrics.

All screens are crops of the project design board. Public facts link to their sources. The Metrics section lists design targets and goals, not measured production results.

**Live site:** https://suvarnamyneni-project.github.io/cubic-translink-merchant-case-study/

## View it

Open `index.html` in a browser. There is no build step.
